# US-POLLUTION-ANALYSIS
PAGE 1: OVERVIEW — US POLLUTION DASHBOARD
1. Project Title:
US Pollution Analysis – Overview

2. Short Description / Purpose:
This dashboard gives a high-level overview of the Air Quality Index (AQI) of four major pollutants — CO, O₃, SO₂, and NO₂ — across US cities and counties, segmented by quarters and time periods.

3. Tech Stack:
Power BI,Power Query. DAX, Bing Maps Integration

4. Data Source:
US EPA (Environmental Protection Agency) Open AQI Data (2006–2010)

5. Features / Highlights:
Pollutant Selection Buttons (CO, O₃, SO₂, NO₂) to drill down into pollutant-wise dashboards.

Quarter-Wise AQI Pie Chart: Shows peak values for each pollutant per quarter.

Dynamic Filters: County, City, State, Date Range, Quarter.

Bing Map Integration: Displays affected locations geographically.

6. Business Insights: Seasonal pollution trends, County-level pollution comparison, Identification of most affected quarters per pollutant.

PAGE 2: CO – CARBON MONOXIDE DASHBOARD
1. Project Title:
CO (Carbon Monoxide) Air Quality Index Analysis

2. Short Description / Purpose:
Visualizes maximum AQI of CO across US states and tracks annual trends from 2006–2010.

3. Tech Stack:
Power BI with custom filters, bar chart, KPI cards, and line chart visualizations.

4. Data Source:
EPA CO pollutant readings (2006–2010)

5. Features / Highlights:
State-wise CO AQI Bar Chart

KPI Cards:

Max CO AQI: 150

Max Hourly Impact: 23 hrs

Highest CO Value: 16.5 ppm

Most Affected City: Mexicali

CO AQI Trend by Year: Shows a clear decline from 2006 to 2010.

6. Insights: CO pollution has significantly decreased over the years, Mexico and border cities are most affected.

PAGE 3: O₃ – OZONE DASHBOARD
1. Project Title:
O₃ (Ozone) Air Quality Index Analysis

2. Short Description / Purpose:
This page tracks AQI levels of Ozone across states and over time.

3. Tech Stack:
Power BI with timeline slicer and performance indicators.

4. Data Source:
EPA AQI data for Ozone (2006–2010)

5. Features / Highlights:
Top States with Highest O₃ AQI (Max: 211)

KPI Cards:

Max O₃ Value: 0.14 ppm

Max Hourly Impact: 23 hrs

Top City: Mexicali

O₃ AQI Trend by Year: Slight fluctuations, peak in 2007, drop in 2009, then rise again in 2010.

6. Insights: O₃ pollution fluctuates year-on-year, Cities in Mexico again show the highest exposure.

PAGE 4: SO₂ – SULPHUR DIOXIDE DASHBOARD
1. Project Title:
SO₂ (Sulphur Dioxide) Air Quality Index Analysis

2. Short Description / Purpose:
Analysis of SO₂ concentration and AQI across US states from 2006 to 2010.

3. Tech Stack:
Power BI with custom filterable charts and regional AQI summaries.

4. Data Source:
EPA AQI Dataset for SO₂ (2006–2010)

5. Features / Highlights:
Bar Chart of Max SO₂ AQI by State

Highest: Oklahoma (200)

KPI Cards:

Max SO₂ Value: 351 ppb

City with Highest SO₂: Park Hill

AQI Trend Line: Continuous decline from 2006 to 2010.

6. Insights: Effective regulation or industrial change likely reduced SO₂ over the years, Park Hill was a major SO₂ hotspot.

PAGE 5: NO₂ – NITROGEN DIOXIDE DASHBOARD
1. Project Title:
NO₂ (Nitrogen Dioxide) Air Quality Index Analysis

2. Short Description / Purpose:
This page focuses on analyzing NO₂ AQI values and trends across different states.

3. Tech Stack:
Power BI dashboard with slicers, bar chart, trend chart, and KPI indicators.

4. Data Source:
EPA Air Quality Index – NO₂ Data (2006–2010)

5. Features / Highlights:
Bar Chart: Max NO₂ AQI by State

Top: Colorado, Louisiana, and California.

KPI Cards:

Max NO₂ Value: 176 ppb

Affected Hours: 23

Most Impacted City: Tijuana

Trend Line: Gradual reduction from 115 AQI in 2006 to 91 AQI in 2010.

6. Insights: Persistent but decreasing NO₂ levels, Border regions like Tijuana are the most exposed.

💡 Combined Impacts of the Dashboard:
Enables policymakers and environmental authorities to track, compare, and act on pollution trends, Helps prioritize resources for regions most affected by specific pollutants, Encourages informed regulation for industrial emissions and traffic planning.
